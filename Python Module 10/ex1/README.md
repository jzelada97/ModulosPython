Exercise 1 — Higher Realm

File: `higher_magic.py`

Functions:
- `spell_combiner(spell1, spell2)` — returns a combined spell that returns both results.
- `power_amplifier(base_spell, multiplier)` — multiplies the `power` argument before calling.
- `conditional_caster(condition, spell)` — calls spell only if condition returns True.
- `spell_sequence(spells)` — returns a function that executes all spells and returns their results.

Run:
python ex1/higher_magic.py
