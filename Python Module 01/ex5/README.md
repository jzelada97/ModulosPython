Exercise 5 — Specialized Plant Types

File: ft_plant_types.py

Spec:
- Create `Flower`, `Tree`, and `Vegetable` classes inheriting from `Plant`.
- `Flower` has `color` and `bloom()`; `Tree` has `trunk_diameter` and `produce_shade()`; `Vegetable` has `harvest_season` and `nutritional_value`.
- Use `super()` where appropriate and override `show()` to include extra info.

Implementation provides the three specialized classes, appropriate methods, and example usage in `__main__`.
