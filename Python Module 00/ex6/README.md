Exercise 6 — Count to Harvest

Files: `ft_count_harvest_iterative.py` and `ft_count_harvest_recursive.py`

Spec:
- Prompt: "Days until harvest: " (int n).
- Print lines: "Day 1" ... "Day n" then "Harvest time!".
- Provide both iterative and recursive implementations in separate files.

Both files implement the required behavior printing each day and the final message.
